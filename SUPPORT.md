# Support

## How to get help

1. Read the [README](README.md) and docs under [`docs/`](docs/).
2. Search [existing issues](https://github.com/mrunalmn4/dup-finder/issues).
3. Open a new GitHub Issue with the bug or feature template.

There is no separate paid support channel for this open-source project.

## What to include in a bug report

- OS and architecture
- Install method (Release asset, `.deb`/`.rpm`, Docker/`ghcr.io`, source)
- Exact command or UI steps
- Expected vs actual behavior
- Whether delete/trash was involved (never paste private file contents)

## Security

See [SECURITY.md](SECURITY.md) — do not file public issues for vulnerabilities.
